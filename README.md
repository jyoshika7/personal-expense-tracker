# Personal Expense Tracker

A Python-based command-line application for recording and managing personal expenses.

## Features

- Add new expenses
- View recorded expenses
- Calculate total expenses
- Store expenses using file handling
- Load previously saved expenses when the application starts

## Technologies Used

- Python
- File Handling
- Functions
- Lists
- Dictionaries
- Loops
- Conditional Statements
